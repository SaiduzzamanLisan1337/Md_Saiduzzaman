# Md. Saiduzzaman — Academic Research Portfolio

A static, GitHub Pages-ready academic portfolio for PhD applications, prospective supervisors, research collaborators, and academic networking.

## Included
- Academic-first research profile
- Professional portrait supplied by the author
- Current master's thesis and advisor
- Verified publications and submission/presentation statuses supplied by the author
- Professional cybersecurity experience
- University-level education
- Professional training
- Technical skills
- Direct email and GitHub contact
- Downloadable CV PDF supplied by the author

## Deploy on GitHub Pages
1. Upload all files and folders in this package to a GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Select the branch containing `index.html` and the root folder (`/`).
4. Save and open the generated Pages URL.

No build system is required.
