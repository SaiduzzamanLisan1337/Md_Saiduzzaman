# Md. Saiduzzaman — Academic Portfolio

A responsive, static academic portfolio for **Md. Saiduzzaman**, focused on AI, machine learning, and cybersecurity research.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; no build step or package installation is required.

## Deploy with GitHub Pages

1. Upload the contents of this repository to the root of the `main` branch of `SaiduzzamanLisan1337/Md_Saiduzzaman`.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub Pages will publish the site at `https://saiduzzamanlisan1337.github.io/Md_Saiduzzaman/`.

## Updating the portfolio

- Replace `assets/Md_Saiduzzaman_CV.pdf` when the CV is updated; keep the filename unchanged so the download button continues to work.
- Update the corresponding sections in `index.html` when education, research projects, publications, experience, skills, or contact details change.
- Keep personal access tokens, passwords, private keys, unpublished sensitive data, and `.env` files out of this public repository.

## External assets

The page loads Google Fonts and Font Awesome from their public CDNs. All portfolio content, documents, styles, and scripts are stored in this repository.
