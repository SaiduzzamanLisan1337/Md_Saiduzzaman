# Saiduzzaman Md. — Academic Portfolio

A formal, research-oriented personal portfolio designed for academic audiences, including professors, prospective PhD supervisors, research collaborators, and graduate admissions committees.

## Positioning

The portfolio deliberately presents an **academic/research profile first** and a **professional cybersecurity profile second**.

The content is based on the information supplied in the CV, with the presentation reorganized for an international academic audience.

## Structure

- Academic Profile
- Research Interests
- Professional Experience
- Academic Education
- Professional Training
- Technical Skills
- Academic Contact

## Design principles

- Formal academic visual language
- Minimalist typography and restrained color palette
- No profile photograph
- No phone number
- No CV-download button
- No unsupported publication claims
- No inflated project list
- Research interests are presented without claiming publications or completed research that is not documented
- Responsive layout for desktop, tablet, and mobile

## Files

- `index.html` — main portfolio page
- `style.css` — layout and visual design
- `script.js` — mobile navigation
- `README.md` — setup information

## GitHub Pages

1. Create a repository named `SaiduzzamanLisan1337.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Updating the portfolio

Keep the academic profile evidence-based. When you later have a verified publication, conference presentation, thesis milestone, research dataset, research software, or laboratory affiliation, add it as a dedicated academic item with the appropriate status (for example, published, submitted, under review, or in progress).

Do not label work as a publication until it has actually been published or formally submitted.
